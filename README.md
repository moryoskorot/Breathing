# Breathing Exercises 🧘‍♂️🌬️

A clean, interactive web application designed to guide users through structured breathing techniques for relaxation, focus, stress relief, and mindfulness.

Made with Claude

🔗 **Try here:** [https://moryoskorot.github.io/Breathing/](https://moryoskorot.github.io/Breathing/)

---

## 📌 Features

- **Interactive Visual Timers & Visualizers**: Real-time pacing cues tailored to each specific breathing pattern.
- **Categorized Techniques**: Covers fundamental, traditional, and advanced breathwork practices:
  - **Foundations**: Box Breathing, Coherent Breathing, 4-7-8 Breathing, Diaphragmatic Breathing, Physiological Sigh, and Nadi Shodhana (Alternate Nostril).
  - **Yoga · Pranayama**: Ujjayi, Bhramari, Lion's Breath, and Sitali.
  - **Advanced Practices**: Wim Hof Method, Kapalabhati, and Bhastrika.
- **Safety & Guidance**: Built-in safety warnings, contraindication alerts, and instructions to ensure safe practice.
- **Responsive & Lightweight**: Works seamlessly across mobile and desktop browsers with zero external dependencies.
